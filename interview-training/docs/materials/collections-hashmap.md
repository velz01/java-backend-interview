# Материалы: HashMap

- [Habr — HashMap под микроскопом](https://habr.com/ru/articles/874728/) — современный подробный разбор внутреннего устройства.
- [Habr — Java собеседование. Коллекции](https://habr.com/ru/articles/162017/) — классические interview-вопросы по коллекциям.
- [Habr — Внутренняя работа HashMap в Java](https://habr.com/ru/articles/421179/) — get/put, hashing, buckets.
- [JavaRush — Подробный разбор класса HashMap](https://javarush.com/groups/posts/2496-podrobnihy-razbor-klassa-hashmap) — большая статья с визуальным объяснением.
- [JavaRush — HashMap и Map в Java](https://javarush.com/groups/posts/1940-klass-hashmap-) — более лёгкий вход в тему.
- [JavaRush — HashMap и ConcurrentHashMap: вопросы с собеседований](https://javarush.com/groups/posts/713-hashmap-i-concurrenthashmap-populjarnihe-voprosih-na-sobesedovanijakh) — follow-up вопросы.

## Картинки и схемы

Лучшие схемы для этой темы — **array of buckets → linked list/tree**, а также схема resize. Они есть в статьях Habr/JavaRush выше. На собеседовании полезно уметь нарисовать такую структуру самостоятельно за 30 секунд.
