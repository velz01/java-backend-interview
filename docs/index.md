## Как пользоваться базой

Не пытайся запомнить текст дословно. Для каждого вопроса пройди три шага: **прочитать → закрыть страницу → ответить вслух → проверить себя follow-up вопросами**.

Если ты уже работал со Spring, SQL, Hibernate и Kafka, проходи базу как систематизацию перед рынком. Если тема новая, сначала разберись в ней практически, затем возвращайся к вопросам.

::: tip Главный принцип
Цель — не знать 100% энциклопедии, а уметь уверенно объяснять ключевые механизмы и рассуждать, когда интервьюер меняет условие задачи.
:::

## Основные блоки

| Блок | Что закрыть в первую очередь |
|---|---|
| Java Core | ООП, equals/hashCode, String, JVM/GC, class loading |
| Collections | HashMap, ArrayList/LinkedList, Set, TreeMap, итераторы |
| Multithreading | synchronized, volatile, happens-before, CAS, executors |
| SQL | JOIN, ACID, isolation, indexes, EXPLAIN, locks |
| Hibernate/JPA | persistence context, lifecycle, LAZY/EAGER, N+1, locking |
| Spring | IoC/DI, bean lifecycle, proxy/AOP, @Transactional, MVC |
| Kafka | partitions, consumer groups, offsets, delivery semantics, retry |
| Architecture | REST, microservices, Saga, Outbox, cache, patterns |
