# XML

## 1. Что такое XML?

XML — текстовый язык разметки для представления структурированных данных. В отличие от HTML, набор тегов не фиксирован: структура определяется самой предметной областью. XML поддерживает вложенность, атрибуты и пространства имён.

## 2. Что такое DTD?

DTD описывает допустимую структуру XML-документа: набор элементов, порядок и вложенность, атрибуты и сущности. Документ можно проверить на соответствие DTD. Ограничение DTD в том, что его собственный синтаксис отличается от XML и возможности типизации ограничены.

## 3. Чем well-formed XML отличается от valid XML?

Well-formed документ соблюдает синтаксические правила XML: один корневой элемент, корректно закрытые и вложенные теги, кавычки у атрибутов и т.д. Valid XML дополнительно соответствует заданной схеме — например DTD или XSD.

## 4. Что такое namespace в XML?

Пространство имён позволяет избежать конфликтов одинаковых имён элементов из разных словарей. Оно связывает prefix с URI и позволяет различать, например, два элемента `<name>`, которые принадлежат разным схемам.

## 5. Что такое XSD и в чём преимущества перед DTD?

XSD — XML Schema Definition. Схема описывается самим XML-синтаксисом, поддерживает богатую систему типов, ограничения значений, namespaces и более точное описание структуры документа. Поэтому XSD заметно мощнее DTD для валидации сложных данных.

## 6. Какие типы существуют в XSD?

Есть простые и сложные типы. Простые типы содержат текстовое значение без вложенных элементов и могут ограничиваться диапазонами, шаблонами и перечислениями. Сложные типы описывают элементы, которые содержат вложенные элементы и/или атрибуты.

## 7. Какие способы чтения XML существуют?

Основные подходы: DOM, SAX и StAX. DOM загружает документ целиком и строит дерево в памяти; с ним удобно произвольно перемещаться по документу, но он потребляет больше памяти. SAX работает событийно и последовательно вызывает callbacks; памяти требуется мало, но произвольного доступа нет. StAX также потоковый, но приложение само запрашивает следующее событие через pull-модель.

## 8. Когда выбирать DOM, SAX или StAX?

DOM удобен для небольших документов, которые нужно многократно обходить или изменять. SAX подходит для очень больших XML, если достаточно последовательной обработки. StAX используют, когда нужна потоковая обработка с большим контролем над тем, когда читать следующий элемент.

## 9. Какие способы записи XML существуют?

XML можно формировать через DOM, потоковые writer API, StAX/XMLStreamWriter или сериализацию объектной модели библиотеками маппинга. Ручная конкатенация строк нежелательна из-за необходимости корректно экранировать специальные символы.

## 10. Что такое JAXP?

JAXP — Java API for XML Processing. Он предоставляет стандартные Java API и фабрики для работы с DOM, SAX, трансформациями и другими XML-механизмами, позволяя выбирать конкретную реализацию парсера.

## 11. Что такое XSLT?

XSLT — язык преобразования XML-документов. С помощью stylesheet можно преобразовать исходный XML в другой XML, HTML или текстовый формат. Шаблоны XSLT выбирают узлы и формируют результирующий документ.
