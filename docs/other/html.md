# Основы HTML

## 1. Что такое HTML?

HTML — язык разметки документов в Web. Он описывает семантическую структуру страницы: заголовки, абзацы, ссылки, списки, таблицы, формы, изображения и другие элементы. Внешний вид обычно задаётся CSS, а поведение — JavaScript.

## 2. Что такое XHTML?

XHTML — применение правил XML к HTML-разметке. Такая разметка требует строгой корректности: закрытых тегов, правильной вложенности и XML-совместимого синтаксиса.

## 3. Что такое DOCTYPE и зачем он нужен?

DOCTYPE сообщает браузеру тип документа и включает стандартный режим рендеринга. Для HTML5 используется `<!DOCTYPE html>`. Без корректного doctype браузер может перейти в quirks mode и использовать старые правила совместимости.

## 4. Для чего предназначен тег head?

`<head>` содержит метаданные страницы: title, meta-теги, ссылки на CSS, favicon и другую служебную информацию. Большая часть содержимого head напрямую не отображается как контент страницы.

## 5. Чем div отличается от span?

`div` — универсальный блочный контейнер, а `span` — универсальный строчный контейнер. Их используют для группировки элементов, когда нет более подходящего семантического тега.

## 6. Как записываются комментарии HTML?

Комментарии записываются как `<!-- комментарий -->` и не отображаются как содержимое страницы.

## 7. Как задаётся ссылка на другой документ?

Для ссылки используется тег `<a>` и атрибут `href`. Например:

```html
<a href="https://example.com/users">Пользователи</a>
```

## 8. Как сделать ссылку на e-mail?

В `href` используется схема `mailto:`. Например:

```html
<a href="mailto:test@example.com">Написать</a>
```

## 9. Для чего предназначен тег em?

`<em>` задаёт смысловой акцент в тексте. Браузеры обычно отображают его курсивом, но главное значение тега — семантическое, а не визуальное.

## 10. Для чего нужны ol, ul и li?

`ol` описывает упорядоченный список, `ul` — неупорядоченный, `li` — отдельный элемент списка.

## 11. Для чего нужны dl, dt и dd?

`dl` задаёт список описаний, `dt` — термин или имя, `dd` — его описание. Такой набор подходит, например, для словарей или списка «параметр — значение».

## 12. Для чего нужны tr, th и td?

Эти теги используются внутри таблицы: `tr` — строка, `th` — заголовочная ячейка, `td` — обычная ячейка данных.

## 13. Зачем нужен alt у img?

`alt` задаёт текстовую альтернативу изображению. Она используется screen reader'ами и отображается, если изображение не загрузилось. Для содержательных изображений корректный alt важен для доступности.

## 14. В каком регистре писать HTML-теги?

HTML5 регистронезависим для имён тегов, но общепринятая практика — писать их в нижнем регистре для единообразия и читаемости.

## 15. Что такое HTML entity?

Entity — специальная запись символа, который неудобно или нельзя вставить напрямую. Например `&lt;` представляет `<`, `&gt;` — `>`, `&amp;` — `&`.
