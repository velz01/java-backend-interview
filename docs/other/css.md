# Основы CSS

## 1. Что такое CSS?

CSS — язык описания внешнего вида HTML/XML-документа. Он задаёт цвета, размеры, отступы, расположение, шрифты и правила адаптивного отображения элементов.

## 2. Как выглядят комментарии CSS?

Комментарии записываются как `/* комментарий */`.

## 3. Что такое selector?

Selector определяет, к каким элементам применится набор CSS-свойств. Например `p` выбирает все абзацы, `.error` — элементы с классом `error`, `#main` — элемент с id `main`.

## 4. Какие основные виды selectors существуют?

Селекторы бывают по тегу, классу, id, атрибуту, псевдоклассу и псевдоэлементу. Также существуют комбинации по потомкам, дочерним и соседним элементам.

## 5. Что такое pseudo-class?

Псевдокласс описывает состояние или положение элемента, например `:hover`, `:focus`, `:first-child`, `:nth-child()`.

## 6. Какие есть attribute selectors?

Можно выбирать элементы по наличию атрибута `[name]`, точному значению `[type="text"]`, началу, окончанию или вхождению части значения через операторы `^=`, `$=`, `*=` и другие.

## 7. Чем #my отличается от .my?

`#my` выбирает элемент по `id="my"`, а `.my` — все элементы, у которых в списке классов есть `my`. Один id должен быть уникален в документе, класс можно использовать многократно.

## 8. Чем margin отличается от padding?

`padding` — внутренний отступ между содержимым и границей элемента. `margin` — внешний отступ между границей элемента и соседними элементами.

## 9. В чём разница между margin: 0 и margin: auto?

`0` явно убирает внешний отступ. `auto` позволяет браузеру вычислить его автоматически. Например, у блочного элемента с заданной шириной `margin-left: auto; margin-right: auto` обычно центрирует его по горизонтали.

## 10. Как задать цвет фона?

Используется свойство `background-color`, например `background-color: red;`.

## 11. Как убрать подчёркивание со ссылок?

Можно задать `a { text-decoration: none; }`.

## 12. Для чего используется clear?

`clear` указывает, с какой стороны элемента не должны находиться плавающие элементы `float`. Например `clear: both` запрещает соседство float-элементов и слева, и справа.

## 13. Как сделать текст всех p жирным?

`p { font-weight: bold; }`.

## 14. Как сделать красным текст элементов класса red?

`.red { color: red; }`.
