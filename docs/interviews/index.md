# Вопросы с реальных собеседований

Раздел подготовлен под дальнейшее наполнение вашими данными.

## Как будет выглядеть запись

- дата / компания / позиция, если это можно публиковать;
- список реально заданных вопросов;
- каждый вопрос ведёт на соответствующую теорию;
- follow-up вопросы интервьюера;
- что кандидат не знал;
- итог интервью;
- счётчик, сколько раз конкретный вопрос встречался.

::: info
Сейчас статистика намеренно не выдумывается. Раздел начнём заполнять реальными собеседованиями учеников.
:::
