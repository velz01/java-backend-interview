# План изучения теории и практики

По менторству писать [сюда](https://teletype.in/@eternalqw/eUSuDpC33PM).

Готовимся к выходу на рынок по трем модулям, при прохождении каждого из модулей пишем ментору что вы его прошли и назначаем мок-собеседование. Перед моком вы должны быть готовы отвечать на теоретические вопросы и решать задачи.
  
Из каждого раздела по лайв-кодингу, код-ревью делаем хотя бы 3 задачи.  
  
Совет: если не понятен какой-либо вопрос, не стесняемся грузить его в нейросеть и спрашивать по одному вопросу еще десять уточняющих.
